## Project Overview

*Pathlyn* is a web-based project that focuses on road safety in Khulna City, Bangladesh. It helps users check road risk levels, find damaged roads, and choose safer routes. The main goal of this project is to help people avoid risky roads and make better travel decisions.

Road accidents can happen for many reasons, such as poor road conditions, heavy traffic, bad weather, and high vehicle speed. Sometimes people do not know which roads are more dangerous or which roads are in poor condition.

To help solve this problem, we developed Pathlyn. Through this platform, users can check road risk information, predict possible road risks, report damaged roads, and compare different routes. There is also an admin panel where authorized staff can check and manage road damage reports.

## Main Features

### 1. Dashboard
- Shows an overview of road safety information.
- Displays risky road locations.
- Shows weather information.
- Provides important road safety alerts.
- Gives easy access to the main features.

### 2. Risk Prediction
- Checks road risk based on different conditions.
- Considers weather and road conditions.
- Considers traffic and vehicle speed.
- Takes the time of day into account.
- Saves previous prediction results.

### 3. Risk Map
- Shows important road locations on a map.
- Displays road risk information.
- Helps users identify roads that may be dangerous.
- Provides a visual view of risky areas.

### 4. Safe Route Planning
- Allows users to select a starting point and destination.
- Shows different route options.
- Provides three choices: Safest, Balanced, and Fastest.
- Compares route distance and estimated travel time.
- Considers available road hazard information when comparing routes.

### 5. Road Damage Reporting
- Allows users to report damaged roads.
- Users can upload images of damaged roads.
- Google Gemini API is used to analyze uploaded images.
- Helps identify the type and level of road damage.
- Saves submitted reports for admin review.

### 6. Admin Panel
- Only authorized staff can access this panel.
- Displays submitted road damage reports.
- Allows admins to review reports.
- Admins can approve, dismiss, or mark reports as resolved.
- Helps manage all submitted reports.

### 7. User Account
- Users can create an account.
- Users can log in and log out.
- The system uses session-based authentication.
- Provides different access permissions for users and admins.
- Normal users cannot access admin-only features.
